# Kikoba Management

Group savings & loans management system for a chama (Benja Kikoba).

- **Web** (React + TypeScript + Vite + Tailwind v4) — admin panel + member portal, EN/SW, mock data. Root of this repo.
- **mobile/** (Flutter) — Android app: admin + member front-end, EN/SW, mock data.

Both are front-end only at this stage (no backend yet). See `SRS`, `SDD`, and the ERD design docs.
